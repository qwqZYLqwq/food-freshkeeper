# 鲜食记 (Food FreshKeeper) - 轻量云端同步服务端

本目录包含「鲜食记」Android 应用的独立轻量同步服务端实现。旨在为用户提供完全自主掌控的私人食材数据云端备份与恢复能力，实现多设备数据同步或防丢备份。

---

## 🌟 核心特性

- **纯零外部依赖**：基于 Python 3 原生标准库（`http.server`、`json`、`os` 等）编写，无需通过 `pip` 安装任何第三方库，开箱即用。
- **环境自适应**：原生适配 Linux VPS、家用 NAS、树莓派，以及 Android PRoot / Termux 等无 systemd 的轻量容器环境。
- **原子性写入保证**：采用临时文件写入与 `os.replace` 原子替换策略，杜绝因服务意外中断导致的数据损坏。
- **高可用与并发**：基于 `ThreadingHTTPServer` 多线程并发模型，保障多客户端高频请求下的平稳响应。
- **标准 RESTful 接口与 CORS 支持**：内置完整跨域头支持，便于浏览器调试及第三方工具扩展。

---

## 📋 环境要求

- **操作系统**：Linux / macOS / Windows / Android (PRoot / Termux)
- **Python 版本**：Python 3.7+ (推荐 Python 3.8 及以上)

## 🚀 快速启动指南

### 1. 启动服务

进入 `server/` 目录，执行启动脚本：

```bash
# 使用默认配置（监听 0.0.0.0:8099）
./start.sh

# 或通过环境变量自定义端口与监听地址
PORT=9000 HOST=127.0.0.1 ./start.sh
```

服务将自动在后台以 `nohup` 模式运行，并将进程 PID 记录于 `server.pid`，运行日志实时输出至 `server.log`。

### 2. 检查运行状态与健康探活

```bash
./status.sh
```

脚本将输出当前服务 PID、端点健康检查返回状态以及最新日志。

### 3. 停止服务

```bash
./stop.sh
```

停止脚本将依据 `server.pid` 优雅终止进程，若超时将自动进行资源清理与端口释放。

## 📡 API 接口规范

所有接口均支持 CORS 跨域调用，数据以 UTF-8 JSON 格式进行交互。

| 方法 | 路径 | 描述 | 请求示例 | 响应示例 (HTTP 200) |
| :--- | :--- | :--- | :--- | :--- |
| `GET` | `/api/health` | 服务健康检查 | 无 | `{"status": "ok", "service": "food-freshkeeper-sync", "version": "1.2.0", "timestamp": 1727230000000}` |
| `GET` | `/api/ping` | 探活接口（兼容老版本） | 无 | `{"status": "ok", "message": "鲜食记同步服务器运行正常", "version": "1.2.0"}` |
| `GET` | `/api/foods` | 拉取最新备份的食材列表 | 无 | `{"status": "ok", "foods": [...], "count": 10, "updatedAt": 1727230000000}` |
| `POST` | `/api/foods` | 上传并持久化食材清单数据 | `{"foods": [...], "timestamp": 1727230000000}` | `{"status": "ok", "count": 10, "updatedAt": 1727230000000, "message": "食材数据备份成功"}` |

> 注：`/api/sync` 端点作为 `/api/foods` 的完全等价别名一并提供支持。

## 📱 鲜食记 Android 客户端对接配置

1. 打开手机上的「鲜食记」应用，进入底栏的「设置」页面。
2. 找到「云端同步与备份」模块。
3. 在「服务器地址」输入框中填入您的服务端地址，格式为：
   ```text
   http://<您的服务器IP>:8099
   ```
4. 点击「测试连接」按钮：
   - 若弹出 `连接成功 (200 OK)`，说明网络与服务运行正常。
   - 若连接失败，请检查服务器防火墙端口 `8099` 是否对外放通，以及手机是否与服务器处于同一局域网或可通过公网访问。
5. 配置成功后：
   - 可开启「数据变动时自动上传」开关，每次新增、编辑或删除食材时将静默同步备份。
   - 也可随时点击「上传本地清单」手动进行全量云端备份，或点击「从云端同步还原」拉取服务器数据。

## 🔒 隐私与安全建议

- 默认配置下，数据保存在服务端脚本同目录的 `foods_data.json` 中。
- 建议仅在受信的局域网或通过个人 VPN/Tailscale/WireGuard 等安全隧道环境下暴露该服务端口。
- 若部署在公网服务器上，建议结合 Nginx/Caddy 等反向代理工具配置 HTTPS 与基础认证 (Basic Auth)。
